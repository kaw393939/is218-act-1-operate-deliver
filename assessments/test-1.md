# Test 1: public preparation specification

[Act home](../README.md) · [Practice brief](practice-brief.md) · [Command reference](../docs/commands.md)

**Individual · Week 4, meeting 2 · 80 minutes total: 5 briefing + 65 execution + 10 handoff.**

This is preparation, not the official exam prompt or an official solution. The instructor supplies the actual assessment repository and finalized handout separately. Practice targets the same skills, with deliberately familiar structure; approximately 90% familiarity is a design target, not a promise of identical tasks or a numerical similarity metric.

## Published skill scope

- Work in the assigned personal fork/repository; verify remote identity.
- Select a virtual environment and install provided dependencies.
- Implement two small arithmetic functions and write six explicit meaningful tests for announced ordinary numeric cases.
- Use issue-linked branches/commits and integrate the requested work into the required submission branch.
- Run the supplied workflow on the submitted revision and record final URL/SHA/run identity.

No classes, REPL, patterns, pandas, web interface, or new CI authoring is required by this preparation scope. Earlier references are worked practice, not a source to copy during assessment.

## Practice resource conditions

No AI generation, repair, chat, or AI completion. No peer assistance. The supplied command reference is permitted for practice; the official handout announces the final permitted materials before timing begins. Report setup/access failures to the instructor. Institutional accommodations remain applicable.

## Example 100-point assessment rubric

| Criterion | Points | How it is established |
| --- | ---: | --- |
| Environment | 25 | Local interpreter/path and dependency evidence, instructor spot-check |
| Behavior | 25 | Submitted functions satisfy the announced arithmetic contract |
| Tests | 25 | Six independently expected cases and correct interpretation of results |
| Git workflow | 15 | Requested issue/branch/commit/integration evidence in personal repo |
| Final verification | 10 | Published full SHA and matching run; correct handoff |

Hosted CI checks submitted tests/behavior at the run revision. It does not prove local environment use, independent authorship, or Git reasoning. Instructor-owned behavior checks and inspection complement workflow output. A materials-only check in an instructor repository must not be presented as a passed student application.

## Official authoring checklist (no answers)

Before release, publish exact function signatures/cases, submission branch, issue requirements, resource conditions, and evidence fields. Provide preconfigured dependencies, ignore file, workflow, and instructions. Keep answer keys and unreleased variations outside public history. Verify the starter workflow distinguishes setup/material checks from actual student behavior checks; rehearse a representative full attempt under timing. Do not invent hidden requirements after the test.

This act repository is the **textbook**. It is not a ready-to-fork official exam starter; the separately issued assessment repository supplies that role.
